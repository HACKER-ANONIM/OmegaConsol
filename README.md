## 📖 О проекте
**OmegaConsol** — это удобный CLI-интерфейс, который объединяет в себе популярные инструменты для пентеста и сетевых манипуляций. Вместо того чтобы запоминать сотни флагов и команд, вы запускаете один скрипт и выбираете нужное действие в интерактивном меню.

## ✨ Возможности
- 🚀 **Omap:** Быстрый запуск сканирования портов через встроенный модуль `Omap.py`.
- 🛡️ **network:** Параметры  сети  .
- 🌐 **search:** Поиск по браузеру.
- ✳️ **skript:OS** контроль ОС
- 🆔 **ping:** проверка активности ip 
- 🎨 **Интерактивное меню:** Удобная навигация по командам (`omap`, `search` и др.).
- 🔎**github:** в консоли будут добавляться запуск других проектов (лежат в папке .github) (не комерческих)
- ❇️**PENTEST** Ваш помошник в работе с сетью и пентэстом

## 🚀 Быстрый старт

### Windows установка
1) скачайте python: https://www.python.org/downloads/release/python-31012/
2) скачайте сам проект с github
3) установи зависимости pip install -r requirements.txt
4) установите wireshark (если хотите чтоб работала функция wireshark:)
5) запустите OmegaConsol.ру

### Внимание  программа, именно зделана под windows  ⚠️
### Большенство функций особено для взоимодействия с ОС не работуют на Linux ⚠️
